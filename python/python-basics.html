9  Python Grundlagen

Dieses Kapitel bietet eine Einführung in die grundlegenden Konzepte von Python, die für Data Science und KI essentiell sind. Für eine praktische Lernerfahrung kann das gesamte Kapitel als Jupyter Notebook heruntergeladen werden:

⬇️ Jupyter Notebook herunterladen

Nach dem Herunterladen kann das Notebook im code Ordner gespeichert und in Jupyter Notebook geöffnet werden.

9.1 Bibliotheken importieren

In Python erweitern Pakete und Bibliotheken die Funktionalität der Sprache. Sie werden am Anfang des Skripts importiert, um den Code übersichtlich und effizient zu gestalten. Oft werden Aliase (Kurzformen) verwendet, um die Bibliotheken im Code einfacher anzusprechen.

Folgender Code importiert wichtige Data Science-Bibliotheken:

# Bibliotheken importieren
import numpy as np      # Für numerische Operationen
import pandas as pd     # Für Datenmanipulation und -analyse
import altair as alt    # Für Datenvisualisierung

Erklärung der importierten Bibliotheken:

  • NumPy (np): Stellt Funktionen für komplexe mathematische Operationen bereit.
  • Pandas (pd): Ermöglicht die effiziente Handhabung und Analyse von strukturierten Daten wie Tabellen.
  • Altair (alt): Bietet eine intuitive Möglichkeit zur Erstellung von interaktiven Visualisierungen.

9.2 Kommentare einfügen

Kommentare sind ein wichtiges Werkzeug zur Dokumentation des Codes. Sie helfen, den Code verständlicher zu machen und erleichtern die Zusammenarbeit mit anderen Entwicklerinnen und Entwicklern. In Python gibt es verschiedene Möglichkeiten, Kommentare zu schreiben.

9.2.1 Einzeilige Kommentare

Einzeilige Kommentare beginnen mit dem #-Zeichen:

# Dies ist ein einzeiliger Kommentar
x = 5  # Kommentare können auch am Ende einer Codezeile stehen

9.2.2 Mehrzeilige Kommentare und Docstrings

Für mehrzeilige Kommentare werden oft dreifache Anführungszeichen verwendet. Diese Art von Kommentar wird auch als “Docstring” bezeichnet, wenn sie direkt nach der Definition einer Funktion, Klasse oder Modul steht:

"""
Dies ist ein 
mehrzeiliger 
Kommentar
"""

def example_function():
    """
    Dies ist ein Docstring für eine Funktion.
    Er beschreibt, was die Funktion tut,  
    welche Parameter sie akzeptiert  
    und was sie zurückgibt.  
    """
    pass

Durch die Verwendung von Docstrings wird der Code nicht nur für Menschen lesbarer, sondern auch für automatisierte Tools zur Dokumentationserstellung zugänglicher. Dies ist besonders in größeren Projekten und bei der Entwicklung von Bibliotheken oder Frameworks von Vorteil.

Verwendung von Kommentaren und Docstrings:

  • Erklärung komplexer Codeabschnitte
  • Dokumentation von Funktionen, Klassen und Modulen (mittels Docstrings)
  • Temporäre Deaktivierung von Code (auch als “auskommentieren” bekannt)
  • Hinzufügen von TODO-Notizen für zukünftige Änderungen

9.3 Variablen und Datentypen

Variablen speichern Informationen im Arbeitsspeicher. Python ist eine dynamisch typisierte Sprache, was bedeutet, dass der Datentyp einer Variable automatisch erkannt wird.

# Verschiedene Datentypen in Variablen speichern
name = "Alice"                      # String (Zeichenkette)
age = 30                            # Integer (Ganzzahl)
height = 5.5                        # Float (Gleitkommazahl)
is_student = True                   # Boolean (Wahrheitswert)
numbers = [1, 2, 3]                 # List (Liste)
person = {"name": "Alice", "age": 30} # Dictionary (Wörterbuch)

Erklärung der Datentypen:

  • String: Textdaten, in Anführungszeichen gesetzt
  • Integer: Ganze Zahlen ohne Dezimalstellen
  • Float: Zahlen mit Dezimalstellen
  • Boolean: Logische Werte (True oder False)
  • List: Geordnete Sammlung von Elementen, veränderbar
  • Dictionary: Sammlung von Schlüssel-Wert-Paaren

Um den Inhalt von Variablen anzuzeigen, wird die print()-Funktion verwendet:

print(name)        # Ausgabe: Alice
print(age)         # Ausgabe: 30
print(numbers)     # Ausgabe: [1, 2, 3]
print(person)      # Ausgabe: {'name': 'Alice', 'age': 30}
Alice
30
[1, 2, 3]
{'name': 'Alice', 'age': 30}

9.4 Operatoren und Berechnungen

Operatoren ermöglichen mathematische und logische Operationen in Python.

9.4.1 Arithmetische Operationen

# Arithmetische Operationen
length = 10
width = 5

Berechnung der Fläche und des Umfangs:

area = length * width           # Multiplikation
perimeter = 2 * (length + width) # Addition und Multiplikation

print(perimeter) # Ausgabe der Variable
30

9.4.2 Vergleichsoperationen

is_square = length == width     # Gleichheit überprüfen

print(f"Ist es ein Quadrat? {is_square}")  # Ausgabe: Ist es ein Quadrat? False
Ist es ein Quadrat? False

is_square überprüft, ob die beiden Seiten gleich lang sind.

Wir nutzen in dem print()-Befehl einen sogenannten f-string (formatted string literal), mit dem wir Text und Python-Objekte kombiniert ausgeben können. Das Python-Objekt wird dabei in einer geschwungenen Klammer eingefügt.

9.4.3 Logische Operationen

is_large_rectangle = (area > 20) and (perimeter > 10)

print(f"Ist es ein großes Rechteck? {is_large_rectangle}")  # Ausgabe: Ist es ein großes Rechteck? True
Ist es ein großes Rechteck? True

is_large_rectangle verwendet logische Operatoren, um festzustellen, ob das Rechteck sowohl eine große Fläche als auch einen großen Umfang hat.

9.4.4 Arten von Operatoren:

  • Arithmetische Operatoren: +, -, *, /, // (Ganzzahldivision), % (Modulo), ** (Potenz)
  • Vergleichsoperatoren: ==, !=, <, >, <=, >=
  • Logische Operatoren: and, or, not

9.5 Arbeiten mit DataFrames

DataFrames, bereitgestellt durch die Pandas-Paket, sind zentral für die Datenanalyse in Python. Sie organisieren Daten in Zeilen und Spalten, ähnlich einer Tabelle.

# Erstellen eines dictionarys
data = {
    "Numbers": [1, 2, 3, 4, 5],
    "Squares": [1, 4, 9, 16, 25]
}

print(data)
{'Numbers': [1, 2, 3, 4, 5], 'Squares': [1, 4, 9, 16, 25]}

Das Dictionary data enthält zwei Listen: Zahlen und deren Quadrate.

Erstellen eines DataFrame mit Pandas:

df = pd.DataFrame(data)

Wir nennen den DataFrame df (dies ist eine gängige Abkürzung für DataFrame). Unser DataFrame wird aus dem Wörterbuch data mit der Funktion pd.DataFrame erstellt, die die Daten in Zeilen und Spalten organisiert.

Den DataFrame ausgeben (dafür verwenden wir nicht print()):

# DataFrame anzeigen
df
Numbers Squares
0 1 1
1 2 4
2 3 9
3 4 16
4 5 25

Das Eingeben von df in eine Jupyter Notebook-Zelle zeigt den DataFrame in tabellarischer Form an.

9.6 Methoden verstehen

Eine Methode ist eine Funktion, die mit einem Objekt (wie einem DataFrame, einer Liste oder einem String) verknüpft ist und über die Punktnotation (.) aufgerufen wird. Dies erleichtert die Manipulation des Objekts und das Abrufen von Informationen.

Hier ein Beispiel der String-Methode .upper(), mit welcher Text in Großbuchstaben ausgegeben werden kann:

# String-Methode
text = "hello, world"
print(text.upper())  # Ausgabe: HELLO, WORLD
HELLO, WORLD

Mit der Methode .sort() können Werte in einer Liste sortiert werden:

# List-Methode
numbers = [3, 1, 4, 1, 5, 9]
numbers.sort()
print(numbers)  # Ausgabe: [1, 1, 3, 4, 5, 9]
[1, 1, 3, 4, 5, 9]

Die folgenden Beispiele sind DataFrame-Methoden des Pakets Pandas, die häufig in Datenprojekten zum Einsatz kommen. Beispielsweise ist .head() eine Methode, welche die ersten Zeilen eines DataFrames anzeigt:

df.head()
Numbers Squares
0 1 1
1 2 4
2 3 9
3 4 16
4 5 25

Die Methode .describe() liefert zusammenfassende Statistiken wie Mittelwert, Anzahl und Standardabweichung. Zusätzlich verwenden wir hier die Methode .round(2), um die Werte auf die zweite Dezimalstelle zu runden:

df.describe().round(2)
Numbers Squares
count 5.00 5.00
mean 3.00 11.00
std 1.58 9.67
min 1.00 1.00
25% 2.00 4.00
50% 3.00 9.00
75% 4.00 16.00
max 5.00 25.00

Zuletzt noch ein Beispiel, wie der Mittlwert mit Hilfe der Methode .mean() berechnet werden kann. Wir erzeugen dafür ein neues Objekt mit der Bezeichnung mean_value und geben dieses dann mit einem f-String aus:

mean_value = df['Numbers'].mean()

print(f"Durchschnitt der Numbers: {mean_value}")
Durchschnitt der Numbers: 3.0

Hier nochmals eine Zusammenfassung der wichtigsten Punkte zu Methoden:

  • Objekt: Eine Entität, die Daten und Funktionalität enthält (z.B. DataFrame, Liste oder String).
  • Methode: Eine Funktion, die mit einem Objekt verknüpft ist.
  • Punktnotation (.): Wird verwendet, um eine Methode auf einem Objekt aufzurufen.

Vorteile von Methoden:

  • Organisieren Funktionalität in logischen Gruppen
  • Ermöglichen objektorientierte Programmierung
  • Verbessern die Lesbarkeit und Wartbarkeit des Codes

9.7 Daten mit Altair visualisieren

Nachdem wir die Struktur eines DataFrames verstanden haben, können wir die Daten mit Hilfe von Altair visualisieren.

Altair ist ein Visualisierungspaket, das auf Vega und Vega-Lite basiert. Es ermöglicht die einfache Erstellung interaktiver und ansprechender Diagramme.

# Einfaches Streudiagramm erstellen
chart = alt.Chart(df).mark_point().encode(
    x='Numbers',
    y='Squares'
)

# Diagramm anzeigen
chart

Komponenten des Altair-Diagramms:

  • alt.Chart(df): Erstellt ein neues Diagrammobjekt aus dem DataFrame df.
  • mark_point(): Gibt den Diagrammtyp an (in diesem Fall ein Streudiagramm).
  • encode: Ordnet DataFrame-Spalten Diagrammattributen zu.
    • x='Numbers': Legt die horizontale Achse auf die Spalte Numbers fest.
    • y='Squares': Legt die vertikale Achse auf die Spalte Squares fest.

Diese prägnante Syntax ermöglicht die schnelle Erstellung und Anpassung von Visualisierungen.
